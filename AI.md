Під час виконання лабораторної роботи використовував ChatGPT для допомоги з переписуванням моделей на record та enum.
Ключовий промпт був таким: "Перероби класи для медичної клініки на record, заміни рядки на enum і напиши switch-вирази для Java 17".
ШІ згенерував усі сутності як record, включно з `Appointment`, проігнорувавши те, що статус у ньому має змінюватися через сеттер.
Крім того, у першому switch-виразі він додав гілку `default`, хоча за умовою був потрібен вичерпний перелік констант без неї.
Я помітив це під час читання вимог варіанта, тому власноруч залишив `Appointment` звичайним класом і прибрав `default`.
Після ручних правок я перевірив коректність збірки через `./gradlew run`
